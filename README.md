
# Конверсия валют

Данный проект может быть использован для перевода указанной суммы из одной выбранной валюты в другую.

## Как установить

Для запроса к серверу необходимо задать ExchangeRate-API key. Для этого создаём файл `.env` и записываем в переменную `EXCHANGERATE_API_KEY` свой ключ.

Python3 должен быть уже установлен. 
Затем используйте `pip` (или `pip3`, есть конфликт с Python2) для установки зависимостей:
```
pip install -r requirements.txt
```

## Пример запуска

```
>>>python main.py
Итоговая сумма: 2084.9 JPY
>>>
```

```
>>>python main.py -a 10 -b USD --target RUB
Итоговая сумма: 748.1610000000001 RUB
>>>
```
